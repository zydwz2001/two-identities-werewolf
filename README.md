# 双身份狼人杀发牌工具

一个面向线下聚会场景的双身份狼人杀规则辅助网站。

这个项目的目标不是“做一个完整桌游平台”，而是先把最耗时、最容易出错的环节自动化：发牌、校验约束、生成可玩的候选方案。

## 这个项目解决什么

- 聚会开局时手动发牌效率低。
- 双身份规则有约束，手工处理容易出错。
- 每局都需要反复重发，影响玩家体验和节奏。

## 核心设计

- 支持 5-8 人局。
- 自动生成符合约束的候选发牌方案。
- 展示狼人阵营、好人阵营、金宝宝和双狼情况。
- 提供角色说明和规则提示，降低新玩家理解成本。

## 规则建模

当前的核心约束包括：

- 每位玩家获得两张身份牌。
- 只要命中一张狼人牌，就属于狼人阵营。
- 狼人和预言家不能落在同一名玩家手中。
- 每局至少保留一个双平民玩家。
- 不同人数使用不同牌库配置，并控制狼人玩家数范围。

## 作品亮点

- 把桌游规则转成了可执行的约束模型。
- 用“随机生成 + 校验循环”的方式，既简单又稳定。
- 把用户最在意的体验点放在“快速开局”和“减少重发”。

## 技术栈

- 单文件静态网站
- 无后端、无外部依赖

## 本地运行

直接打开 `index.html` 即可。

如果想用本地服务：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```
