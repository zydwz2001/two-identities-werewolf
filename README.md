# 双身份狼人杀发牌工具

一个面向线下聚会场景的双身份狼人杀规则辅助网站。

这个项目的目标不是“做一个完整桌游平台”，而是先把最耗时、最容易出错的环节自动化：发牌、校验约束、生成可玩的候选方案。

## 项目背景

双身份狼人杀在朋友聚会里很受欢迎，但手工发牌容易因为规则约束而反复重来。尤其是特殊身份冲突、狼人玩家数控制和金宝宝保留等条件，常常让开局效率变差。

## 技术方案

- 使用单文件静态页面实现完整流程，避免后端依赖。
- 把角色配置、规则约束、候选生成和结果展示放在同一页面内完成。
- 通过“随机生成 + 约束校验 + 重试”的方式得到可用发牌方案。

## 实现逻辑

- 根据参与人数选择对应牌库配置。
- 先生成一组候选身份分配，再检查是否满足狼人阵营、预言家冲突、金宝宝等规则。
- 如果校验不通过就继续重试，直到得到可展示的候选方案。
- 页面同时展示规则说明和方案解释，降低新玩家上手成本。

## 设计取舍

- 优先解决“快速开局”和“减少重发”，而不是做复杂桌游后台。
- 优先把规则模型显式化，保证结果可解释。
- 优先保留单页可用性，方便线下聚会直接打开使用。
